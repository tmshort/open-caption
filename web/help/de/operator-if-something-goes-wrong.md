# Wenn etwas schiefgeht

**Es wurde die falsche Zeile gesendet.** Drücken Sie die **Rücktaste**, um sie zurückzunehmen, und dann die **Leertaste**, wenn der richtige Moment kommt.

**Eine Zeile wurde gestrichen oder wird nicht gesprochen.** Drücken Sie **S** (oder **Überspringen**), um sie zu übergehen, ohne sie zu senden; das Publikum sieht nichts, und die **Rücktaste** nimmt es zurück.

**Sie haben die Stelle verloren.** Klicken Sie auf die Zeile, die als Nächstes kommen soll, und bestätigen Sie „Hierher springen“, oder drücken Sie `/` und tippen Sie ein paar Wörter aus der Zeile.

**Eine Durchsage muss raus.** Mit **Durchsage …** bringen Sie großen Text auf alle Bildschirme, etwa „Die Show geht gleich weiter“. Er bleibt bis zur nächsten Zeile. Die **Rücktaste** entfernt ihn.

**Die Publikumsbildschirme sollen dunkel werden.** Drücken Sie **B**. Drücken Sie noch einmal **B**, um die Untertitel zurückzubringen.

**Die Untertitel auf dem Bildschirm sind unübersichtlich.** Drücken Sie **C**, um sie zu leeren.

**„Ein anderer Operator hat die Steuerung.“** Jemand anderes oder ein anderer Tab dieser Seite steuert die Show. Wenn Sie das selbst sind, nutzen Sie **Übernehmen**.

**Die Seite meldet, dass sie getrennt ist.** Der Punkt wird rot, und die Seite verbindet sich von selbst neu. Die Position der Show bleibt auf dem Server erhalten, es geht also nichts verloren. Wenn sie nicht innerhalb weniger Sekunden zurückkommt, laden Sie die Seite neu; Sie landen dort, wo Sie waren.

**Der Server wurde neu gestartet.** Er merkt sich, wo die Show war, und macht dort weiter; Sie bleiben angemeldet und haben weiter die Steuerung. Eine laufende Schleife beginnt wieder beim ersten Element. Die **Rücktaste** macht weiterhin die letzten Dinge rückgängig, die Sie vor dem Neustart gesendet haben.

**Beim Drücken von Tasten passiert nichts.** Klicken Sie zuerst auf eine leere Stelle der Seite und prüfen Sie, dass kein Fenster (wie diese Hilfe) geöffnet ist.
