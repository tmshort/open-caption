# Anzeigen

| Was Sie sehen | Was es bedeutet |
|---------------|-----------------|
| Roter Balken unter der Kopfzeile, „Verbindung zum Programm verloren“ | Die Seite erreicht das Programm nicht. Sie verbindet sich von selbst neu und der Balken verschwindet; es geht nichts verloren |
| **● AUF SENDUNG** | Die Show ist auf Sendung: das Publikum sieht sie |
| **STANDBY** und ein bernsteinfarbenes Banner | Das Publikum sieht den Standby-Bildschirm des Hauses und nichts von der Show. Die **Leertaste** (**START**) bringt sie auf Sendung |
| Personensymbol und eine Zahl | Wie viele Publikumsgeräte verbunden sind. Bei mehreren Sprachen folgt auf die Zahl eine Zählung je Sprache, etwa `(en 60 · es 23)` |
| **Sie haben die Steuerung** | Ihre Tasten steuern die Show |
| **Ein anderer Operator hat die Steuerung** | Sie können zusehen, aber nichts senden. **Übernehmen** nimmt sie ihm ab |
| **Sie verfolgen diese Show (nur Ansicht)** | Sie haben sich mit dem Zuschauer-Passwort angemeldet: Sie können mitlesen, Notizen eingeschlossen, aber nichts senden und nichts übernehmen |
| Gelbes Banner **Der Publikumsbildschirm ist leer** | Das Publikum sieht einen leeren Bildschirm (Ausblenden oder Stopp wurde benutzt). **Leertaste** sendet die nächste Zeile, **B** zeigt die früheren wieder, **Rücktaste** macht es rückgängig |
| Grünes Banner **SCHLEIFE LÄUFT** | Eine Schleife vor der Show oder in der Pause ist auf den Bildschirmen |
| **Ende der Show.** | Es gibt keine weiteren Zeilen zu senden |
| **Zuletzt gesendet vor 12 s** | Zeit seit dem letzten Senden durch den Operator. Wird nach zwei Minuten gelb. Hat die Zeile auf dem Bildschirm ein `[pace]` in der Show-Datei, folgt `· Next is due in 6 s`, dann ein gelbes `· Next is due` |
| Ausgeblendete Schaltflächen | Sie haben nicht die Steuerung, die Bedienelemente sind also aus |
| `BILD: Name` | Auf den Publikumsbildschirmen wird ein Bild gezeigt; Sie sehen nur seinen Namen |
| `NOTIZ:` (violett) und Lesezeichen (blau) | Nur für Sie; das Publikum sieht sie nie |
