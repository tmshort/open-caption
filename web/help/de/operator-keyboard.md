# Tastatur

Diese Tasten funktionieren, solange Sie nicht in ein Feld tippen und kein Fenster geöffnet ist.

| Taste | Aktion |
|-------|--------|
| `Leertaste`, `Pfeil rechts`, `Bild ab`, `Eingabe` | **Weiter:** sendet die nächste Zeile; startet eine Schleife, die als Nächstes kommt; beendet eine laufende Schleife und sendet die Zeile danach |
| `Rücktaste`, `Pfeil links`, `Bild auf` | **Zurück:** macht die letzte Aktion rückgängig. Das Zurückgehen in eine Schleife startet sie neu |
| `Umschalt+Q` | **Stopp:** stoppt eine laufende Schleife und lässt einen leeren Bildschirm |
| `B` | **Ausblenden** oder Einblenden: verbirgt alles und bringt beim Einblenden dieselben Untertitel zurück |
| `C` | **Leeren**: löscht die Untertitel, damit die nächste Zeile auf einem leeren Bildschirm beginnt |
| `/` | In der Show-Datei suchen |
| `Pos1` | Die Show neu starten (fragt zuerst nach) |
| `Esc` | Einen Sprung abbrechen oder ein Fenster schließen |

Wartet ein Sprung auf Bestätigung, bestätigt **Eingabe** ihn, statt die nächste Zeile zu senden.

Gedrückt gehaltene Tasten wiederholen sich nicht, und zwei Tastendrücke innerhalb einer Bruchteilssekunde zählen als einer; ein prellender Klicker überspringt also keine Zeile.

Die Seite ignoriert alle diese Tasten, solange dieses Hilfefenster geöffnet ist; das Lesen der Hilfe kann also nie eine Zeile an das Publikum senden.

Die Tasten werden nach dem Zeichen erkannt, das sie erzeugen, nicht nach ihrer Position auf der Tastatur; sie funktionieren daher auf QWERTY, AZERTY, QWERTZ und anderen Belegungen gleich. Auf einem Mac heißt die Rücktaste **delete** (⌫), und die Schaltflächen auf dem Bildschirm zeigen dieselben Symbole wie die Tasten: ␣ für die Leertaste, ⌫ für die Rücktaste und ⇧ für Umschalt. Auf einem Telefon oder Tablet ohne Tastatur verwenden Sie die großen Schaltflächen unten auf der Seite.
