# Teclado

Estas teclas funcionam sempre que você não estiver digitando numa caixa e nenhuma janela estiver aberta.

| Tecla | Ação |
|-------|------|
| `Espaço`, `Seta para a direita`, `Page Down`, `Enter` | **Próximo:** envia a próxima linha; inicia um laço que é o próximo; encerra um laço em andamento e envia a linha seguinte a ele |
| `Backspace`, `Seta para a esquerda`, `Page Up` | **Voltar:** desfaz a última ação. Voltar a um laço o reinicia |
| `Shift+Q` | **Parar:** para um laço em andamento e deixa a tela em branco |
| `B` | **Em branco** ou desfazer o branco: esconde tudo, e traz de volta as mesmas legendas ao desfazer |
| `C` | **Limpar**: apaga as legendas, para que a próxima linha comece numa tela vazia |
| `/` | Buscar no arquivo do espetáculo |
| `Home` | Reiniciar o espetáculo (pergunta antes) |
| `Esc` | Cancelar um salto ou fechar uma janela |

Se um salto estiver esperando confirmação, o **Enter** o confirma em vez de enviar a próxima linha.

Teclas mantidas apertadas não se repetem, e dois toques com uma fração de segundo entre eles contam como um, então um controle remoto com ruído não pulará uma linha.

A página ignora todas essas teclas enquanto esta janela de ajuda estiver aberta, de modo que ler a ajuda nunca pode enviar uma linha ao público.
