# Indicadores

| O que você vê | O que significa |
|---------------|-----------------|
| Ponto verde no alto à direita | Conectado ao servidor. Vermelho significa que a conexão caiu; a página se reconecta sozinha |
| **● AO VIVO** | O espetáculo começou (pelo menos uma linha foi enviada) |
| Ícone de pessoas e um número | Quantos dispositivos do público estão conectados. Com vários idiomas, o número é seguido de uma contagem por idioma, como `(en 60 · es 23)` |
| **Você tem o controle** | Suas teclas controlam o espetáculo |
| **Outro operador tem o controle** | Você pode assistir mas não enviar. **Assumir** tira o controle dele |
| Faixa amarela **A tela do público está em branco** | O público vê uma tela em branco (Em branco ou Parar foi usado) |
| Faixa verde **LAÇO EM ANDAMENTO** | Um laço de pré-espetáculo ou de intervalo está nas telas |
| **Fim do espetáculo.** | Não há mais linhas para enviar |
| **Último envio há 12 s** | Tempo desde que o operador enviou algo pela última vez. Fica amarelo depois de dois minutos |
| Botões esmaecidos | Você não tem o controle, então os comandos estão desligados |
| `IMAGEM: nome` | Uma imagem é mostrada nas telas do público; você vê só o nome dela |
| `NOTA:` (roxo) e marcadores (azul) | Só para você; o público nunca os vê |
