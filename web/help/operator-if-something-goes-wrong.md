# If something goes wrong

**The wrong line was sent.** Press **Backspace** to take it back, then press **Space** when the right moment arrives.

**You lost your place.** Click the line you want to be next and confirm "Jump here", or press `/` and type a few words from the line.

**A message needs to go out.** Use **Message…** to put large text on every screen, such as "The show will resume shortly". It stays until the next line. **Backspace** removes it.

**The audience screens should go dark.** Press **B**. Press **B** again to bring the captions back.

**The captions on screen are cluttered.** Press **C** to clear them.

**"Another operator is in control."** Someone else, or another tab of this page, is controlling the show. If that is you, use **Take over**.

**The page says it is disconnected.** The dot turns red and the page reconnects by itself. The show position is kept on the server, so nothing is lost. If it does not return within a few seconds, reload the page; you will land where you were.

**The server was restarted.** It remembers where the show was and carries on from there. A running loop starts over from its first item.

**Nothing happens when I press keys.** Click on an empty part of the page first, and check that no window (such as this help) is open.
