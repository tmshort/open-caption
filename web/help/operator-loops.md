# Loops for the operator

A loop is a set of full-screen pictures and text that repeats, used before the show and at intermission. In your list it appears as `LOOP — 4 items`; click to see what it contains.

- A loop at the very start of the show file is **the pre-show**: it begins when the show goes on air (**Space**, on START), and the next press of **Space** ends it and sends the first line.
- A loop later in the show file (for example intermission) starts when you press **Space** on it. While it runs, a green banner says **LOOP RUNNING**.
- **Space** ends the loop and sends the line after it.
- **Shift+Q** stops the loop and leaves the screen blank. Press **Space** to continue.
- **Backspace** after the loop has ended or been stopped brings the loop back, starting again from its first item.
- If the loop has a **timer** (a countdown such as 15 minutes for the intermission, or a time such as 7:30pm for the pre-show), the green banner also shows the time left, counting down live (`⏱ 13 min left on the timer`). The audience sees it wherever the loop's text says the countdown. A minutes timer starts when the loop starts, so **Backspace** back into the loop starts it again from the full time.

Everyone's screens change together, including the projector, because the server runs the timer.
