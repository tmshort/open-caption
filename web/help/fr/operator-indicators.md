# Indicateurs

| Ce que vous voyez | Ce que cela signifie |
|-------------------|----------------------|
| Barre rouge sous l'en-tête, « Connexion au programme perdue » | La page ne peut pas joindre le programme. Elle se reconnecte toute seule et la barre disparaît ; rien n'est perdu |
| **● EN DIRECT** | Le spectacle est à l'antenne : le public le voit |
| **EN ATTENTE** et un bandeau ambre | Le public voit l'écran d'attente du lieu et rien du spectacle. **Espace** (**DÉMARRER**) le met à l'antenne |
| Icône de personnes et un nombre | Combien d'appareils du public sont connectés. Avec plusieurs langues, le nombre est suivi d'un décompte par langue, comme `(en 60 · es 23)` |
| **Vous avez la main** | Vos touches pilotent le spectacle |
| **Un autre opérateur a la main** | Vous pouvez regarder mais pas envoyer. **Reprendre la main** la lui retire |
| **Vous suivez ce spectacle (lecture seule)** | Vous vous êtes connecté avec le mot de passe spectateur : vous pouvez regarder, notes comprises, mais rien ne peut être envoyé et il n'y a rien à prendre en main |
| Bandeau jaune **L'écran du public est vide** | Le public voit un écran vide (Écran vide ou Arrêt a été utilisé). **Espace** envoie la ligne suivante, **B** réaffiche les précédentes, **Retour arrière** annule |
| Bandeau vert **BOUCLE EN COURS** | Une boucle d'avant-spectacle ou d'entracte est à l'écran |
| **Fin du spectacle.** | Il n'y a plus de lignes à envoyer |
| **Dernier envoi il y a 12 s** | Temps écoulé depuis le dernier envoi de l'opérateur. Devient jaune après deux minutes. Si la ligne à l'écran a un `[pace]` dans le fichier de spectacle, il continue par `· Next is due in 6 s`, puis un `· Next is due` jaune, avec une fine barre le long de la bande qui se remplit avec le temps et devient jaune quand la pression suivante est due (et un cadre jaune autour de la ligne suivante) |
| Boutons estompés | Vous n'avez pas la main : les commandes sont désactivées |
| `IMAGE : nom` | Une image est montrée sur les écrans du public ; vous n'en voyez que le nom |
| `NOTE :` (violet) et signets (bleu) | Pour vous seul ; le public ne les voit jamais |
