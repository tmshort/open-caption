# Keyboard

These keys work whenever you are not typing in a box and no window is open.

| Key | Action |
|-----|--------|
| `Space`, `Right arrow`, `Page Down`, `Enter` | **Next:** send the next line; start a loop that is next; end a running loop and send the line after it. In standby it is **START**: it puts the show on air |
| `Backspace`, `Left arrow`, `Page Up` | **Back:** undo the last action. Backing into a loop restarts it |
| `Shift+Q` | **Stop:** stop a running loop and leave a blank screen |
| `B` | **Blank** or unblank: hide everything, and bring the same captions back when you unblank |
| `C` | **Clear**: erase the captions, so the next line starts on an empty screen |
| `/` | Search the show file |
| `Home` | Restart the show: back to the beginning and to standby (asks first) |
| `Esc` | Cancel a jump or close a window |

If a jump is waiting for confirmation, **Enter** confirms it instead of sending the next line.

Keys held down do not repeat, and two presses within a fraction of a second count as one, so a bouncing clicker will not skip a line.

The page ignores all of these keys while this help window is open, so reading help can never send a line to the audience.

The keys are matched by the character they type, not by where they sit on the keyboard, so they work the same on QWERTY, AZERTY, QWERTZ and other layouts. On a Mac the Backspace key is labelled **delete** (⌫), and the on-screen buttons show the same symbols as the keys: ␣ for Space, ⌫ for Backspace and ⇧ for Shift. On a phone or tablet without a keyboard, use the large buttons at the bottom of the page.
